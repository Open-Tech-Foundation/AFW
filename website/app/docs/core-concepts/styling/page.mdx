# Styling

AFW is unopinionated about styling — use whatever you like.

## Global CSS

Import a stylesheet from `index.html` or your entry, and use `class` as usual:

```jsx
<div class="card">…</div>
```

## CSS Modules

Files named `*.module.css` are scoped — class names are hashed and imported:

```jsx
import styles from "./Card.module.css";

<div class={styles.card}>…</div>
```

## Tailwind CSS

Tailwind CSS 4 works in both workflows. Start the stylesheet with its import and use
utility classes in `class`:

```css
/* app/global.css */
@import "tailwindcss";
```

```jsx
<button class="rounded-md bg-sky-600 px-3 py-1 text-white">Save</button>
```

**Vite + Node** — add the Tailwind Vite plugin after AFW's
(`npm create @opentf/afw -- --styling=tailwind` sets this up):

```bash
npm install -D tailwindcss @tailwindcss/vite
```

```js
// vite.config.js
import afw from "@opentf/vite-plugin-afw";
import tailwindcss from "@tailwindcss/vite";

export default { plugins: [afw(), tailwindcss()] };
```

**esdev + ES-Runtime** — no plugin and no config: install `tailwindcss` and import it.
esdev compiles the stylesheet with the project's own Tailwind
([esdev's Tailwind guide](https://esrun.opentechf.org/esdev/build/tailwind)).

```bash
npm install -D tailwindcss
```

Either way:

- Classes are found by scanning the project's source files, `.jsx`, `.tsx` and `.mdx`
  included, in both string and object `class` values.
- A class must appear in full in the source: write `done ? "line-through" : ""`, not a
  name assembled from pieces.
- `node_modules` is not scanned. For a component library that uses Tailwind classes, add
  its folder with `@source "../node_modules/my-lib";`.
- Tailwind v3 (configured through PostCSS) is not supported by esdev; use v4.

## Inline styles

Pass a style object (camelCased properties). Values can be reactive:

```jsx
<div style={{ color: active ? "tomato" : "inherit", padding: "1rem" }} />
```

## Dynamic classes

A class bound to a signal updates in place:

```jsx
<span class={done ? "line-through" : ""}>{text}</span>
```
