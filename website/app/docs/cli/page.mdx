# CLI

AFW has no CLI of its own. Each workflow uses its toolchain's commands, with AFW's plugin
compiling JSX, TSX and MDX and discovering routes.

## esdev + ES-Runtime

`@opentf/esdev-plugin-afw` runs inside esdev, which bundles, processes CSS, runs tests
and manages the development loop.

| Command | Purpose |
| --- | --- |
| `esdev create my-app` | Create a project (prompts for template, language and package manager). |
| `esdev start` | Build and watch the targets in `esdev.json`; runs the server target in full-stack mode. |
| `esdev build --minify` | Build release output. |
| `esdev preview` | Serve the static release output. |
| `esdev test --config=esdev.test.json --dom` | Run tests in the native DOM realm. |
| `esdev test --config=esdev.test.json --browser` | Run tests in a real browser. |
| `esdev typecheck` | Run the project's TypeScript checker. |

- Configure plugins and build targets in `esdev.json`. A browser app needs an HTML entry
  whose module script imports `@afw/routes` and calls `mountApp`.
- Static generation adds a prerender target with `then: run`; a full-stack app adds a
  server target that serves `@afw/server`. See
  [Production Build](/docs/deployment/build) and [Server Setup](/docs/deployment/server).
- The development loop is esdev's: see its
  [development guide](https://esrun.opentechf.org/esdev/start).

## Vite + Node

`@opentf/vite-plugin-afw` runs inside Vite; server code runs on Node.

| Command | Purpose |
| --- | --- |
| `npm create @opentf/afw@latest` | Create a project: `app`, `docs` or `library`; see [Installation](/docs/getting-started/installation). |
| `vite` (`npm run dev`) | The dev server, with API routes, loaders and server functions on Node. |
| `vite build` (`npm run build`) | Build release output, and `dist/server` when the app has server code. |
| `node dist/server/index.js` (`npm start`) | Run the built server (`PORT`, `HOST`). |
| `vite preview` | Serve a static build. |
| `vitest run` (`npm test`) | Run component and page tests with `@opentf/afw-test`. |

- Configure the plugin in `vite.config.js`: `afw({ mode: "spa" | "ssr" | "ssg" })`. See
  the [plugin's options](https://github.com/Open-Tech-Foundation/afw/tree/main/packages/vite-plugin-afw#options).
