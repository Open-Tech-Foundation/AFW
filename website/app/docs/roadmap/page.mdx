# Roadmap

This page tracks what developers coming from React, Vue, Svelte or Solid reach for
every day that AFW does not have yet: some of it those frameworks build in, the rest
comes from their package ecosystems. It complements [Comparison](/docs/comparison),
which compares full-stack framework features.

<Callout type="info" title="Surveyed November 2026">
  Items are checked off as they land. The detailed engineering roadmap lives in
  [`docs/roadmap.md`](https://github.com/Open-Tech-Foundation/afw/blob/main/docs/roadmap.md).
</Callout>

## Framework features

These items need compiler or runtime support, so a third-party package cannot add them.

### Components and rendering

- [x] **Enter and exit transitions.**
  - Animate elements as conditionals and lists add or remove them: [Transitions](/docs/core-concepts/transitions), in the next release.
  - Others: Vue `<Transition>`, Svelte `transition:`, Framer Motion `AnimatePresence`.
- [ ] **List reorder animation and out-in mode.**
  - Animate items that move within a list, and let the old element finish leaving before the new one enters.
  - Others: Svelte `animate:flip`, Vue `<TransitionGroup>` and `mode="out-in"`.
- [x] **Async pending boundaries.**
  - [`<Pending>`](/docs/data-fetching/pending) shows one fallback while the resources inside load, keeps the content during a refetch, and sends a failed first load to the nearest `<ErrorBoundary>`. In the next release.
  - Others: React and Solid `<Suspense>` and transitions, Svelte `{#await}` and `<svelte:boundary>`.
- [ ] **Typed data after loading.**
  - Inside `<Pending>`, `resource.data` is still typed `T | undefined`.
  - Others: React `use()`, TanStack `useSuspenseQuery`.
- [ ] **Lazy components.**
  - Load a component's code only when it first renders, such as a modal, editor or chart.
  - Others: React `lazy()`, Solid `lazy()`, Vue `defineAsyncComponent`.
  - Today: pages and layouts are code-split; other components are bundled with the page that imports them.
- [ ] **Shadow DOM styles.**
  - Opt-in style isolation per component.
  - Today: [CSS Modules](/docs/core-concepts/styling) scope class names.

### Routing

- [x] **Per-route loading and error files.**
  - [`loading.jsx` and `error.jsx`](/docs/routing/loading-and-errors), in the next release.
- [ ] **Layout errors.**
  - `error.jsx` covers the page; an error thrown by a layout is reported, not caught.
- [ ] **Layout loaders.**
  - Today: loaders run for pages only.
- [ ] **Route groups and optional segments.**
- [ ] **Typed routes.**
  - Check `<Link href>` and `navigate()` paths, and type `params`, against the `app/` folder.
  - Others: TanStack Router, React Router type generation.
- [ ] **Validated search params.**
  - Parse `query` with a schema into typed values, and update one value without building the URL by hand.
  - Others: TanStack Router `validateSearch`, Nuxt `useRoute().query`.
  - Today: pages receive `query` as a plain string map.
- [x] **Scroll restoration for async pages.**
  - Each history entry's position is restored after the page renders, retrying while it grows: [Navigation](/docs/routing/navigation#scroll-position), in the next release.
- [x] **View transitions.**
  - `mountApp({ viewTransitions: true })`: [Navigation](/docs/routing/navigation#view-transitions), in the next release.

### Data and forms

- [ ] **Forms without JavaScript.**
  - `<form action={addTodo}>` posts to a server action and works before hydration; actions can redirect.
  - Others: SvelteKit form actions, React Router `<Form>`, Next.js server actions.
- [ ] **Query caching and single-flight updates.**
  - Opt-in cache and deduplication for `query()`, and an action response that carries the refreshed data.
- [ ] **Streaming server rendering.**

### Configuration and tooling

- [ ] **Public environment variables.**
  - Expose `PUBLIC_*` variables to the browser in both toolchains.
  - Today: expose browser values explicitly through build configuration.
- [ ] **Lint rules.**
  - An ESLint plugin that flags macro misuse (such as `$state` outside a component) in the editor instead of at build time.
- [ ] **Editor support.**
  - Complete TSX typings and editor tooling for macros.
- [ ] **Devtools.**
  - Inspect components, signals and network activity.
- [ ] **Image optimization.**
  - An image component plus a build step for responsive sizes and modern formats.

## Ecosystem bridges

React, Vue and Svelte developers install these from npm. Many libraries publish a
framework-agnostic core; AFW needs a thin adapter or a tested guide for each.

| Need | What others use | Works in AFW today | Planned |
| --- | --- | --- | --- |
| Server-state cache, retries, optimistic updates | TanStack Query, SWR | `@tanstack/query-core` by hand | Signals adapter |
| Tables and virtual lists | TanStack Table, TanStack Virtual | Their core packages by hand | Signals adapters |
| Accessible UI primitives: dialog, menu, combobox | Radix, Headless UI, Ark, Bits UI | Web component libraries such as Web Awesome or Material Web; Floating UI for positioning | Tested guide |
| Persisted state | Zustand `persist`, Pinia plugins | Module-level `signal()` with your own `localStorage` code | Helper for persisted and cross-tab state |
| Authentication | Auth.js, Better Auth | Fetch-based libraries through [middleware](/docs/routing/middleware) and [cookies](/docs/routing/cookies) | Guide and example |
| Real-time updates | Socket.IO, server-sent events helpers | Browser `WebSocket` and `EventSource` on the client | Server guide for both toolchains |
| Animation | Framer Motion, GSAP | Motion or GSAP on a `$ref`, or returned from a [custom transition](/docs/core-concepts/transitions#custom-transitions) | Reorder animation (above) |
| Component workbench | Storybook, Histoire | Not verified | Preset or guide |
| Offline and installable apps | `vite-plugin-pwa` | Not verified | Guide for both toolchains |

## Already covered

- **First-party packages:** [forms](/packages/afw-form), [i18n](/packages/afw-i18n), [component testing](/packages/afw-test) and the [docs theme](/packages/afw-docs).
- **Components:** context, portals, error boundaries, CSS Modules and Tailwind.
- **Server:** middleware, cookies, API routes, and typed server functions with schema validation and same-origin checks on actions.
- **Content:** page metadata, sitemap, MDX.
- **Development:** hot reload that keeps component state.
