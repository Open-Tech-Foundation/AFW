# Library Template

Component libraries ship JSX/TSX source from `index.js`. Apps compile that source with
their own AFW plugin, so the library does not bundle a second copy of the framework.

| Workflow | Command |
| --- | --- |
| esdev | `esdev create my-lib --template=library` |
| Vite | `npm create @opentf/afw my-lib -- --template library` |

Both write the same project:

- `index.js` (the package entry) and `src/Counter.jsx`;
- a preview app (`app/page.jsx`, run by `dev`), which is not published;
- a component test in `tests/ui/`, run by `test`;
- `--styling tailwind` for Tailwind classes, `--language js` for JavaScript.

## Using a library in an app

- Install it next to `@opentf/afw`, a peer dependency (a caret range). Nothing to
  configure.
- Both AFW plugins compile every dependency that declares `@opentf/afw` (as a peer or a
  dependency), in the dev server, in builds and in tests.
- A library that uses Tailwind classes needs `@source "../node_modules/my-lib";` in the
  app's stylesheet, since Tailwind does not scan `node_modules`.

## Package entry

```js index.js
// The package entry: export each component.
export { default as Counter } from "./src/Counter.jsx";
```

- `package.json` publishes `index.js` and `src/` (its `files` list).
- `@opentf/afw` is a peer dependency, and a dev dependency for the preview and tests.

## Sample component

```jsx src/Counter.jsx
export default function Counter({ start = 0 }) {
  let count = $state(start);
  const doubled = $derived(count * 2);

  return (
    <p>
      <button onclick={() => count++}>Count: {count}</button> Doubled: {doubled}
    </p>
  );
}
```

## Tests

The same test file runs in both workflows: it imports its test API from
`@opentf/afw-test/test` (esdev's `runtime:test`, or Vitest).

```js tests/ui/Counter.test.js
import { expect, test } from "@opentf/afw-test/test";
import { render, userEvent } from "@opentf/afw-test";
import { Counter } from "../../index.js";

test("counts clicks", async () => {
  const { getByRole, getByText } = render(Counter, { start: 1 });
  await userEvent.setup().click(getByRole("button", { name: "Count: 1" }));
  expect(getByRole("button").textContent).toBe("Count: 2");
  expect(getByText(/Doubled: 4/)).toBeTruthy();
});
```

| Workflow | `test` runs |
| --- | --- |
| esdev | `esdev test --dom --setup=@opentf/afw-test/setup tests/ui` |
| Vite | `vitest run` (`happy-dom`, with `@opentf/afw-test/vitest` as the setup file) |
